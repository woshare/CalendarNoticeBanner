## 一、技术问题修复

### 1. 替换 print() 为 os.Logger

**问题：** 生产包中存在 6 处 `print()` 调试语句，输出至系统控制台，存在信息泄漏风险，且无法按级别过滤。

**涉及文件：**
- `CalendarMonitor.swift`（5 处）
- `BannerWindowController.swift`（1 处）

**方案：** 在每个文件顶部创建 `os.Logger` 实例，替换所有 `print()`。

```swift
import os
private let logger = Logger(subsystem: "com.meetbell", category: "CalendarMonitor")

// 替换前
print("[MeetBell] forceCheckNow: 找到 \(count) 个事件")

// 替换后
logger.debug("forceCheckNow: 找到 \(count) 个事件")
```

**日志级别规范：**
| 场景 | 级别 |
|------|------|
| 正常流程信息 | `.debug`（仅 Debug 构建可见）|
| 权限、启动等关键节点 | `.info` |
| 操作失败、权限拒绝 | `.error` |

### 2. 修复 Layout 常量不一致（实际 Bug）

**问题：** `BannerView.Layout` 与 `BannerWindowController` 各自硬编码尺寸，且数值不匹配：

| 常量 | BannerView.Layout | BannerWindowController | 差异 |
|------|-------------------|------------------------|------|
| bodyH / bannerH | 80 | 80 | ✓ 一致 |
| oarExtra | **25** | **22** | ✗ 差 3pt |
| panelH | **130** | **124** | ✗ 差 6pt |

面板实际申请高度（124pt）小于视图需要高度（130pt），导致龙舟船桨顶部和底部被系统裁剪 3pt。

**方案：** 将 `Layout` 从 `private` 改为 `internal`，`BannerWindowController` 直接引用 `BannerView.Layout` 常量，删除本地重复定义。

```swift
// BannerView.swift — 去掉 private
enum Layout {
    static let headW:    CGFloat = 82
    static let tailW:    CGFloat = 56
    static let bodyH:    CGFloat = 80
    static let oarExtra: CGFloat = 25
    static var panelH:   CGFloat { bodyH + oarExtra * 2 }  // 130
}

// BannerWindowController.swift — 删除本地常量，改为引用
let bannerH  = BannerLayout.bodyH      // 80
let oarExtra = BannerLayout.oarExtra   // 25（修复：原来是 22）
let panelH   = BannerLayout.panelH     // 130（修复：原来是 124）
```

> 注：`Layout` 重命名为 `BannerLayout` 避免与其他框架类型冲突。

### 3. 订阅 EKEventStore 变更通知（实时响应日历变动）

**问题：** `CalendarMonitor` 每 60 秒轮询一次。用户在 Calendar.app 中新增或修改事件后，最多需要等待 60 秒才触发提醒重新计算，存在漏提醒风险。

**方案：** 在 `start()` 中订阅 `EKEventStore.changedNotification`，事件变动时立即调用 `checkNow()`。

```swift
// CalendarMonitor.swift — start() 中新增
NotificationCenter.default.addObserver(
    self,
    selector: #selector(calendarStoreChanged),
    name: .EKEventStoreChanged,
    object: eventStore
)

@objc private func calendarStoreChanged() {
    eventStore.refreshSourcesIfNecessary()
    checkNow()
}
```

**防抖处理：** 日历批量同步时 `EKEventStoreChanged` 可能短时间内连续触发多次，需加 1 秒防抖，避免重复计算：

```swift
private var changeDebounceTask: DispatchWorkItem?

@objc private func calendarStoreChanged() {
    changeDebounceTask?.cancel()
    let task = DispatchWorkItem { [weak self] in
        self?.eventStore.refreshSourcesIfNecessary()
        self?.checkNow()
    }
    changeDebounceTask = task
    DispatchQueue.main.asyncAfter(deadline: .now() + 1.0, execute: task)
}
```

同时在 `stop()` 中取消订阅：
```swift
NotificationCenter.default.removeObserver(self, name: .EKEventStoreChanged, object: eventStore)
```

## 二、横幅皮肤系统（Banner Skin）

### 设计目标

- 当前龙舟 UI 作为**默认皮肤**
- 支持多套皮肤，用户在偏好设置中选择
- 支持**随机模式**：每次弹出横幅随机选一套皮肤
- 新皮肤可独立开发，不影响现有代码

### 架构方案

**定义皮肤协议：**

```swift
// Banner/BannerSkin.swift
enum BannerSkinID: String, CaseIterable, Codable {
    case dragonBoat = "dragon_boat"   // 默认：龙舟
    case minimal    = "minimal"        // 简约风格
    case random     = "random"         // 随机
}
```

**BannerView 根据皮肤 ID 切换渲染器：**

```swift
// BannerView.swift
struct BannerView: View {
    // ...
    var body: some View {
        let effectiveSkin = resolvedSkin  // random 时在此处选取
        switch effectiveSkin {
        case .dragonBoat: DragonBoatCanvasView(...)
        case .minimal:    MinimalBannerView(...)
        case .random:     fatalError("已在 resolvedSkin 处理")
        }
    }

    private var resolvedSkin: BannerSkinID {
        if preferences.bannerSkin == .random {
            return BannerSkinID.allCases
                .filter { $0 != .random }
                .randomElement() ?? .dragonBoat
        }
        return preferences.bannerSkin
    }
}
```

**PreferencesStore 新增字段：**

```swift
var bannerSkin: BannerSkinID {
    get {
        let raw = defaults.string(forKey: Keys.bannerSkin) ?? BannerSkinID.dragonBoat.rawValue
        return BannerSkinID(rawValue: raw) ?? .dragonBoat
    }
    set { defaults.set(newValue.rawValue, forKey: Keys.bannerSkin); objectWillChange.send() }
}
```

**SettingsView 新增皮肤选择：**

```
Section("横幅皮肤") {
    Picker("皮肤", selection: $preferences.bannerSkin) {
        Text("🐉 龙舟（默认）").tag(BannerSkinID.dragonBoat)
        Text("✨ 简约").tag(BannerSkinID.minimal)
        Text("🎲 随机").tag(BannerSkinID.random)
    }
    .pickerStyle(.inline)
}
```

### v0.0.3 内置皮肤清单

| 皮肤 | 描述 | 状态 |
|------|------|------|
| 龙舟（dragonBoat） | 现有动画龙舟，绿色船身金色龙头 | ✅ 已有 |
| 简约（minimal） | 纯色渐变背景 + 文字，无动画 | 📋 新增 |
| 随机（random） | 每次弹出随机选取一个皮肤 | 📋 新增 |

## 三、macOS 版本兼容性（支持 macOS 12）

### 问题

当前部署目标为 macOS 13.0，macOS 12.x（Monterey）用户安装时直接报错拒绝运行。

### 受影响的 API 清单

| API | 所在文件 | 最低要求 | 现状 |
|-----|---------|---------|------|
| `SMAppService.mainApp.register/unregister` | SettingsView.swift | macOS 13.0 | 直接调用，无版本判断 |
| `.formStyle(.grouped)` | SettingsView.swift | macOS 13.0 | 直接调用，无版本判断 |
| `EKEventStore.requestFullAccessToEvents` | CalendarMonitor.swift | macOS 14.0 | ✅ 已有 `#available(macOS 14.0, *)` |
| `TimelineView` / `Canvas` | BannerView.swift | macOS 12.0 | ✅ 无需改动 |

### 方案：部署目标降至 macOS 12.0

**① 修改 project.pbxproj**

将所有 `MACOSX_DEPLOYMENT_TARGET = 13.0` 改为 `12.0`（共 6 处）。

**② SMAppService 兼容处理**

`SMAppService` 仅在 macOS 13+ 可用。macOS 12 回退方案：引导用户手动在「系统偏好设置 → 用户与群组 → 登录项」中添加。

```swift
// SettingsView.swift
Section("开机启动") {
    if #available(macOS 13.0, *) {
        Toggle("开机时自动启动", isOn: Binding(
            get: { SMAppService.mainApp.status == .enabled },
            set: { enable in
                // 现有逻辑不变
            }
        ))
        if let msg = launchStatusMessage {
            Text(msg).font(.caption).foregroundColor(.secondary)
        }
    } else {
        // macOS 12 回退：引导手动设置
        VStack(alignment: .leading, spacing: 6) {
            Text("开机自动启动")
                .font(.body)
            Text("请在「系统偏好设置 → 用户与群组 → 登录项」中手动添加 MeetBell。")
                .font(.caption)
                .foregroundColor(.secondary)
            Button("打开登录项设置") {
                NSWorkspace.shared.open(
                    URL(string: "x-apple.systempreferences:com.apple.preferences.users")!
                )
            }
            .buttonStyle(.bordered)
        }
    }
}
```

**③ .formStyle(.grouped) 兼容处理**

```swift
// SettingsView.swift
var body: some View {
    Form { ... }
        .modify {
            if #available(macOS 13.0, *) {
                $0.formStyle(.grouped)
            } else {
                $0  // macOS 12 使用默认 Form 样式
            }
        }
        .frame(width: 420, height: 600)
}
```

为避免 `#available` 分散在 body 里，使用 View extension：

```swift
extension View {
    @ViewBuilder
    func modify<T: View>(@ViewBuilder _ transform: (Self) -> T) -> some View {
        transform(self)
    }
}
```
