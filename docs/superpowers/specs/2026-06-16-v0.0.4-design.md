# MeetBell v0.0.4 设计文档

**日期：** 2026-06-16
**分支：** feature/release-v0.0.4
**范围：** 节日皮肤自动切换、横幅结束时间展示、进出动画

---

## 一、目标

v0.0.4 在 v0.0.3 皮肤系统基础上做三件事：

1. 新增节日主题皮肤，按日期自动切换
2. 横幅显示会议结束时间，让用户一眼知道会议时长
3. 横幅进出动画流畅化，消除生硬的突然出现/消失

---

## 二、架构总览

不引入新大模块，在现有结构上扩展：

| 文件 | 变更 |

## 三、节日皮肤系统

### 3.1 BannerSkinID 新增 case

```swift
case auto            = "auto"           // 按日期自动选择
case springFestival  = "spring_festival" // 春节
case lanternFestival = "lantern_festival" // 元宵
case qingming        = "qingming"        // 清明
case dragonBoatFest  = "dragon_boat_fest" // 端午（节日触发器，复用龙舟视觉）
case midAutumn       = "mid_autumn"      // 中秋
case christmas       = "christmas"       // 圣诞
```

### 3.2 日期范围（固定阳历窗口）

| case | 月/日范围 | 说明 |
|------|-----------|------|
| springFestival | 1/20 – 2/10 | 覆盖农历年前后 |
| lanternFestival | 2/11 – 2/17 | 元宵节前后 |
| qingming | 4/3 – 4/6 | 清明固定窗口 |
| dragonBoatFest | 5/28 – 6/10 | 端午前后 |
| midAutumn | 9/10 – 9/30 | 中秋浮动窗口 |
| christmas | 12/20 – 12/26 | 圣诞前后 |

日期表存为 `BannerSkin.swift` 内的静态数组，无需农历换算。

### 3.3 `.auto` 解析逻辑

```
resolved() 中：
  .auto → 按当前月/日遍历节日表，命中则返回对应节日 case
          未命中则返回 .dragonBoat（默认）
```

`.random` 现有逻辑不变，只从非 auto/非 random 的 case 中随机选取。

### 3.4 视觉方向（HolidayBannerView）

| 节日 | 底色 | 装饰元素 |
|------|------|----------|
| 春节 | 红色 | 金色灯笼、烟花粒子（Canvas） |
| 元宵 | 深红 | 灯笼串、星点 |
| 清明 | 浅绿 | 柳枝图案（复用龙舟底座配色） |
| 端午 | 复用现有龙舟皮肤 | — |
| 中秋 | 深蓝 | 月亮 + 星星（Canvas 绘制） |
| 圣诞 | 墨绿 | 雪花飘落动画（Canvas） |

`HolidayBannerView` 接受与 `MinimalBannerView` 相同的参数签名，内部根据 `resolvedSkin` 切换配色和装饰。

## 四、结束时间展示

### 4.1 数据

`CalendarEvent` 已有 `endDate`，无需模型变更。

### 4.2 展示格式

- 有结束时间：`10:00–10:45`（起止连写，en dash 分隔）
- 结束时间与开始时间同一天时只显示时分，不重复日期
- 跨天会议：`23:00–次日 01:00`（中文标注"次日"）

### 4.3 位置

放在横幅标题下方时间行，紧跟倒计时文字后面（或替换为起止时间 + 倒计时组合展示）：

```
[会议标题]
10:00–10:45  ·  5分钟后
```

两个视图（`BannerView`、`MinimalBannerView`）都加，样式与各自风格保持一致。

### 4.4 设置开关

`PreferencesStore` 新增：
```swift
@AppStorage("com.meetbell.showEndTime") var showEndTime: Bool = true
```

Settings"显示内容"区块新增 Toggle：
```
Toggle("结束时间", isOn: $preferences.showEndTime)
```

## 五、进出动画

改造集中在 `BannerWindowController`，SwiftUI 视图层不变。

### 5.1 进场动画（show）

1. 窗口初始 frame：目标位置向上偏移 `panelH` 像素（窗口在屏幕外）
2. `alphaValue = 0`
3. `NSAnimationContext.runAnimationGroup` duration 0.35s，`timingFunction: easeOut`
4. 动画内将 frame 移至目标位置，`alphaValue → 1`

### 5.2 退场动画（close/dismiss）

1. `NSAnimationContext.runAnimationGroup` duration 0.25s
2. 动画内 `alphaValue → 0`
3. `completionHandler` 里调用 `window.orderOut(nil)`

### 5.3 兼容性

`NSAnimationContext` 在 macOS 12+ 均可用，无需 `#available` 版本门控。

Snooze 触发的关闭走同一 `dismiss` 动画路径，不另做处理。

## 六、不在本版本范围内

- 农历精确换算（固定阳历窗口足够用）
- 节日皮肤的用户自定义颜色
- 横幅进场音效
- 多个会议同时提醒的堆叠逻辑
